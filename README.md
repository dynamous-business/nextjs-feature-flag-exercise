# Agentic Engineering Workshop

Exercise repository for the Agentic Engineering Workshop.

## Exercises

| Branch | Description |
|--------|-------------|
| exercise-1 | Baseline - establish your AI-assisted coding workflow |
| exercise-2 | PIV Loop - learn Planning → Implementing → Validating with reusable commands |
| exercise-3 | Group exercise - identify team workflows to automate as commands |

## Getting Started

To work on an exercise, checkout the corresponding branch:

```bash
git checkout exercise-1
```

Each exercise branch contains its own README with detailed instructions.
